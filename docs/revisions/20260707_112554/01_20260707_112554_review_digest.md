# 2026-07-07 Review Digest

## Bottom Line

The manuscript is structurally close to a preprint, but it should not be
uploaded to EarthArXiv before the preprocessing and validation QA issues are
resolved or explicitly reframed.

The paper should answer one question:

> Can public fire-perimeter, weather, fuel, and terrain data retrospectively rank
> transmission-line segments by historical external wildfire exposure, and can a
> Bayesian posterior convert a single ranked list into an uncertainty-aware
> priority set?

It should not answer:

- which line caused a fire;
- which device failed;
- which line will trip;
- where an outage will occur;
- how a future fire will spread;
- whether an internal business algorithm is operationally accurate.

## Stable Manuscript Core

- Receptor assets: transmission-line segments are exposed assets, not ignition
  sources.
- Public data: CEC, CAL FIRE FRAP, gridMET, LANDFIRE, USGS 3DEP.
- Panel: 11,255 segments and 78,785 segment-year observations.
- Main label: `exogenous_fire_exposure`, with CAUSE = 11 excluded.
- Holdout: 2017-2021 training, 2022-2023 evaluation.
- Bayesian value: posterior rank probability, especially
  `P(rank in top 10% | D)`.

## Main Review Findings

### P0 Data QA

1. LANDFIRE unit decoding is a blocker.
   - CH raw value likely needs `/10`.
   - CBH raw value likely needs `/10`.
   - CBD raw value likely needs `/100`.
   - FBFM40 is categorical and must not be treated as a continuous hazard value.

2. Annual weather summaries create possible within-year look-ahead leakage if
   the manuscript claims prospective prediction.
   - Current annual features are acceptable only under a retrospective observed
     annual-condition framing.

3. M5 selection history must be verified.
   - If M5 was selected after inspecting 2022-2023 performance, the holdout is
     contaminated by model selection.
   - If M5 was pre-specified, the manuscript must state that.

### P0/P1 Validation QA

4. Segment-year independence is too strong.
   - Repeated years per segment, spatially adjacent segments, overlapping
     buffers, and large fire perimeters all create dependence.
   - Posterior rank probabilities may be overconfident.

5. Probability calibration is weak.
   - Holdout prevalence is 356 / 22,510 = 1.58%.
   - A climatology predictor has Brier score about `pi * (1 - pi) = 0.01557`.
   - Current model Brier scores are slightly higher than this baseline.
   - Ranking may be useful even if absolute probability skill is not yet
     positive.

## Recommended V1 Framing

Use:

> Retrospective public-data external wildfire exposure ranking of
> transmission-line segments under observed annual environmental conditions.

Avoid:

- prospective screening;
- forecasting;
- before-fire prediction;
- operational warning;
- future risk probability.

## Preferred Primary Bayesian Quantity

Primary:

```text
rho_i = P(rank_down(pbar_i) <= K | D)
```

Secondary diagnostic:

```text
q_i = P(pbar_i > tau | D)
```

Reason: `rho_i` is rank-focused and more robust to monotone calibration
problems than threshold exceedance probability.
