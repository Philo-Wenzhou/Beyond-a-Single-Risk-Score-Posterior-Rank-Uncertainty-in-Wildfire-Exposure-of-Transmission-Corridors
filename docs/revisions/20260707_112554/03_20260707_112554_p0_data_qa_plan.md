# P0 Data QA Plan

## Objective

Audit whether current LANDFIRE and feature-construction code is suitable for a
public preprint. This must happen before claiming anything about fuel variables
or physics-guided fuel structure.

## P0.1 LANDFIRE Unit Decoding

Check scripts and processed model tables for:

- `landfire_canopy_height_m`
- `landfire_canopy_base_height_m`
- `landfire_canopy_bulk_density`

Expected raw-code conversions to verify:

```text
CH_m = CH_raw / 10
CBH_m = CBH_raw / 10
CBD_kg_m3 = CBD_raw / 100
```

Questions:

1. Does Phase 3 divide CH and CBH by 10 before writing model tables?
2. Does Phase 3 divide CBD by 100 before writing model tables?
3. Were old figures made from raw values or decoded values?
4. Were model features made from raw values or decoded values?
5. Are any derived features affected by raw scaling?

## P0.2 FBFM40 Handling

FBFM40 is a categorical fire-behavior fuel model code. It must not be treated as
a continuous hazard value without an explicit, cited mapping.

Audit:

- Is `landfire_fbfm40` included directly in any regression feature set?
- Is its mean used as a continuous fuel-severity metric?
- Does `phys_fuel_structure_index` use FBFM40 raw code?

Acceptable current outcomes:

1. FBFM40 is not used in the final selected model; document that.
2. FBFM40 is used only for categorical summaries; document encoding.
3. If raw continuous use is found, mark current model outputs as needing rerun.

## P0.3 Spatial Support Mismatch

Current labels use a 1 km buffer, but covariates may be sampled at segment
midpoints.

Audit:

- DEM aggregation: midpoint or buffer?
- LANDFIRE aggregation: midpoint pixel or buffer summary?
- gridMET aggregation: nearest grid cell, segment mean, or buffer mean?

If midpoint-only fuel sampling is confirmed, do not claim LANDFIRE has weak
predictive value. State that fuel covariates require buffer-scale reconstruction.
